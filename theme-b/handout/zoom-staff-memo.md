# Zoom 担当への依頼メモ

```
・講師の PC を Zoom で画面共有します。Zoom 側の音声と共有が見えているか、開始前に確認をお願いします。
・Zoom チャットは会場に映しません。視聴者が仕様書のことを書いても大丈夫です。
・投票 1〜3 を、講師の合図で出してください（時刻は台本にあります）。
・30 分時点で「設計者として見落としは?」を視聴者に聞きます。チャットの内容を 2〜3 件、声で講師に伝えてください。
・52 分の振り返りでも同じく、視聴者の書き込みを 2〜3 件伝えてください。
・視聴者から質問が来たら、講師の話の切れ目で伝えてください。答えられないものは「終了後に文書で」で構いません。
```

## Zoom 投票 3 本

| 番号 | 出すタイミング | 質問 | 選択肢 |
|---|---|---|---|
| 投票 1 | 22 分（deploy 前） | AI が書いた 3 本のテスト、何本が緑（成功）になると思いますか | 0 本 / 1 本 / 2 本 / 3 本 |
| 投票 2 | 38 分（赤が出た直後） | 赤になった原因は 4 つのうちどれだと思いますか | ① アプリの欠陥 / ② テストの間違い / ③ 環境 / ④ データ |
| 投票 3 | 52 分（振り返り） | 自分の現場で AI にテストを書かせるなら、最初に渡すものは何ですか | 仕様書 / 動く画面 / 既存のテスト / まだ分からない |

会場の参加者は同じ質問にチャットで番号を書く。Zoom 担当が両方の集計を講師に伝える。
