🆘
- `npm run deploy` が赤字で止まる → エラーの先頭 3 行をチャットに貼らせる。`auth` や `401` → `now-sdk auth --list` に `mypdi` があるか確認、無ければ登録し直す。`scopeId` → `atf-tests\now.config.json` の scopeId が空。`.\setup.ps1 -SkipNpm -SkipInstall` を打ち直す（1 分）。
